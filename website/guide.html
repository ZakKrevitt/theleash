SETUP / USER GUIDE

Stay with the thing.

Leash gives one task a clear finish line, then notices when another app pulls you away. Setup takes about a minute.

Install Leash

  1. Download Leash-macOS-v0.1.0.dmg.
  2. Open the disk image and drag Leash onto the Applications shortcut.
  3. Eject the Leash disk image in Finder.
  4. Open Leash from Applications or Spotlight.

Leash requires macOS 14 or later and runs on Apple Silicon and Intel Macs. It lives in the menu bar, so no Dock window opens.

No special permissions. Leash does not ask for Accessibility, Screen Recording, Input Monitoring, or Automation access.

Set your first leash

  1. Open the Mac apps you expect to use for the task.
  2. Click the Leash icon in the menu bar.
  3. Name the task in plain language, such as Send the revised deck.
  4. Choose a finish line. Write one outcome or make a checklist.
  5. Pick the main app. This is the anchor Leash returns you to.
  6. Allow any other open apps the task genuinely needs.
  7. Choose a timer and an intervention, then start.

If an app is missing from the picker, open it first. Leash lists apps that are running now.

Catch me

Leash shows a prompt beside the cursor when you enter an unrelated app. The app stays open. The catch is saved in Later so you can return to it after the task.

Pull me back

Leash saves the unrelated app in Later, hides it, and brings the anchor forward. Hiding is reversible. The app is not quit and its work is not discarded.

During a leash

The companion stays out of sight while you work in the anchor or another allowed app. It appears when Leash catches a drift, the timer ends, or you finish.

Need another app?

Open Leash from the menu bar and add the app to the active session. Keep the list narrow enough that the leash still means something.

Want something from Later?

Later records the app where a catch happened, not the page, tab, window title, or document. Use it as a short reminder list after the current task ends.

Finish, extend, or release

Choose Finish when the finish line is true. A checklist can finish only after every item is checked.

When time runs out, finish the task, add 10 minutes, or release the leash without recording a completion.

Emergency release: press Control-Option-Command-L from anywhere. Closing the anchor app also releases the session.

Troubleshooting

I opened Leash but nothing appeared

Look for the Leash icon on the right side of the menu bar. Leash is a menu bar app and does not open a normal window or Dock icon.

An app is missing

Launch the app, reopen the Leash menu, and check the picker again.

The global release shortcut is unavailable

Another app may already use that key combination. Release and Quit remain available in the Leash menu. Quit the conflicting app, then restart Leash to register the shortcut again.

Pull me back made an app disappear

The app was hidden, not closed. Click its icon in the Dock or use Command-Tab to bring it back.

Leash does not notice a browser tab change

Version 0.1 watches app changes. Tabs inside one browser count as the same app.

The app will not open after download

Use the current DMG from the official Leash download page. Move Leash into Applications before launching. If macOS reports that the app is damaged or cannot be verified, download it again and contact support instead of bypassing Gatekeeper.

Verify a download

Compare the DMG against the published SHA-256 file:

shasum -a 256 -c Leash-macOS-v0.1.0.dmg.sha256

After installation, macOS can verify the Developer ID signature and notarization:

codesign -d --verbose=4 /Applications/Leash.app
spctl --assess --type execute --verbose=4 /Applications/Leash.app

An official build has Team ID QWT6LQP2GH.

Update or uninstall

Update

Quit Leash, open the new DMG, and replace the old copy in Applications. Your local settings remain in place.

Uninstall

  1. Choose Quit from the Leash menu.
  2. Move /Applications/Leash.app to the Trash.
  3. To remove Leash preferences and Later data, open Terminal and run defaults delete com.zakkrevitt.leash.

Privacy

Leash stores the active session and Later app identities in local macOS preferences. It does not read window titles, URLs, page contents, documents, screenshots, clipboard data, or keystrokes. It contains no account, analytics, telemetry, crash reporter, or network client.
